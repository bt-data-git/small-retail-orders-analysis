# Small Retail Orders Analysis

## Project Overview
This project analyses a small retail orders dataset containing 70 customer orders.

The aim was to practise core Excel data analysis skills by cleaning and preparing the dataset, creating calculated fields, building PivotTables and producing a dashboard to summarise sales performance.

The analysis focused on monthly revenue, order volume, customer contribution, average order value and repeat customer behaviour.

## Tools Used
- Microsoft Excel
- PivotTables
- Calculated Columns
- Charts
- Conditional Formatting
- Data Cleaning

## Data Cleaning
Before analysis, I prepared the dataset by:

- Checking the dataset structure and column names
- Ensuring order dates and shipping dates were formatted correctly
- Creating month fields for time-based analysis
- Creating a month number field so months could be sorted chronologically
- Checking order totals, quantities and customer names for consistency
- Correcting formatting issues where needed

The dataset contained 62 orders in January and 8 orders in February. The February data only covered the beginning of the month, so direct monthly comparisons were interpreted carefully.

## Analysis
I used Excel PivotTables to explore:

- Revenue by month
- Order count by month
- Revenue by customer
- Average order value by month
- Customer retention across January and February

I also used conditional formatting in the retention table to make repeat customers easier to identify.

## Key Findings
- January accounted for the majority of order activity, with 62 of the 70 total orders.
- February contained only 8 orders and covered only the beginning of the month, limiting direct comparison with January.
- A small number of customers contributed a larger share of total revenue.
- Average order value helped distinguish whether lower revenue was associated with fewer orders or differences in order size.
- Repeat customers were identified across January and February using a customer retention PivotTable.

The final dashboard summarises revenue, order volume, average order value and top customers.
